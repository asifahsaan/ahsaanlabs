# Ahsaan Labs

Free, interactive AI explainers that walk through every calculation step by step.
Live site: https://asifahsaan.github.io/ahsaanlabs/

**Deep Learning labs (available):** Neural Network, CNN, RNN, LSTM and GRU.
**On the way:** AI algorithms, Machine Learning, NLP, AI agents, Transformer.

Each lab is a single HTML file that works offline. All maths runs in your browser and is cross-checked against a Python reference.

If these labs help you teach or learn, please **star the repo** and **follow [@asifahsaan](https://github.com/asifahsaan)**.

## Build

The labs in `dl/` are generated from `src/`:

```bash
cd src
python build.py nn cnn rnn lstm
```
